# Blog Receiver Example

Standalone receiver for blogs from the Travel SEO Dashboard.

**Setup:**
1. Copy your Website ID from the dashboard (Websites page → Copy ID)
2. Open `server.js` and replace `paste_your_site_id_here` with your ID
3. Run: `npm install && npm start`
4. In the dashboard, add your website with URL: `http://localhost:4000` (for local testing) or your production URL
5. Publish a blog from the dashboard targeting this site

**Production:** Deploy this to the same domain as your travel site, or add these routes to your existing backend.
